🚀 생초보도 5분 만에 만드는 웹 프로그램 실행법

1

제미나이 프롬프트 입력 및 전송

실습 워크벤치 탭에서 원하는 프로그램의 [제미나이 프롬프트 복사] 버튼을 누른 후, 제미나이 채팅창에 붙여넣고 입력합니다.

2

코드 블록 전체 복사

제미나이가 짜준 HTML 코드를 복사합니다. 코드 블록 우측 상단의 '복사' 또는 'Copy' 아이콘을 클릭하면 깔끔하게 원본 코드가 복사됩니다.

3

메모장에 코드 붙여넣기 및 저장

윈도우 메모장(Notepad)을 실행하고 코드를 붙여넣습니다.
[파일] -> [다른 이름으로 저장]을 선택하고, 파일명을 seat_arranger.html 형태로 적습니다. 반드시 파일 형식을 '모든 파일(*.*)'로 설정하고, 인코딩 형식을 'UTF-8'로 지정한 뒤 저장해 주세요.

4

더블클릭하여 브라우저에서 실행

저장된 파일을 마우스로 더블클릭하면 교실 크롬(Chrome)이나 엣지(Edge) 브라우저에서 인터넷 연결 없이도 즉각 실행되는 독립적인 프로그램이 가동됩니다.

⚠️ 흔히 겪는 에러 및 해결 방법 (FAQ)

❌ 한글이 이상한 문자로 깨져서 나와요

이유: 메모장에서 저장할 때 인코딩 방식을 지정하지 않아서 생기는 한국어 깨짐 현상입니다.
해결책: 파일을 저장할 때 하단의 인코딩 방식을 'ANSI'가 아닌 'UTF-8'로 선택해 주시면 완벽히 해결됩니다.

💡 내가 원하는 새로운 기능(소리 등)을 넣고 싶어요

방법: 제미나이에게 추가 대화를 건네어 코드를 개선해 보세요.
"방금 짜준 코드에서 버튼을 누르면 귀여운 당첨 효과음이 나오도록 사운드 생성(Web Audio API) 코드를 추가해줘" 라고 말하면 다시 코드를 줍니다.

❌ 브라우저를 껐다 켜면 학생 명단이 다 사라져요

이유: 임시로 명단을 메모리상에만 들고 있어서 초기화되는 현상입니다.
해결책: "브라우저 로컬 스토리지(localStorage)에 학생 명단을 저장하게 고쳐줘. 그래서 껐다 켜도 자동으로 불러와지게 해줘." 라고 말하세요.

💡 프로그램 아이디어가 없을 땐 어떡하죠?

방법: 제미나이에게 교실 내 고민을 털어놓으세요.
"나는 초등학교 교사야. 학급 운영을 하면서 학생들이 1인 1역 청소를 제대로 수행했는지 기록하고 체크하는 예쁜 웹 대시보드를 만들고 싶어. 단일 파일 HTML로 구현할 수 있는 상세한 기획과 소스코드를 작성해줘."
