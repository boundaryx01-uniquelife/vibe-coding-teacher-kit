🔍 바이브 코딩 4대 프롬프트 작성 공식 (구조 해설)

제미나이가 코딩 에러 없이 교실에서 사용할 수 있는 완성형 단일 HTML 웹 앱을 만들어내는 필수 프롬프트 구조입니다.

1. 목표 및 환경 제약

📦 단일 파일 (Single-File) 강제

HTML, CSS, JS를 단 하나의 파일로 묶고 더블클릭만으로 실행 가능한 오프라인 환경임을 명시합니다.

2. 디자인 및 레이아웃

🎨 교실 모니터 최적화 UI

글래스모피즘, 파스텔톤, 칠판 프레임 등 구체적인 visual 주제와 반응형 레이아웃 테마를 지시합니다.

3. 핵심 동작 규칙

⚡ 사용자 경험 & 오프라인 기술

드래그앤드롭 자리 교환, 브라우저 내장 TTS 음성, Canvas 폭죽 등 독립 작동 로직을 세부 요구합니다.

4. 데이터 영속성

💾 localStorage 데이터 저장

학생 명단이나 학급 설정이 새로고침이나 브라우저 재시작 후에도 자동 보존되도록 지시합니다.
