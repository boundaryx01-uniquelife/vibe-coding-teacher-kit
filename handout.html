[연수 유인물] AI 활용 바이브 코딩 학급운영 프로그램 만들기

전문적 학습 공동체(전학공) 연수 자료 | 대상: 코딩 초보 교사

1. 바이브 코딩(Vibe Coding)이란?

복잡한 코딩 문법을 공부할 필요 없이, 교사가 자연어(일반 검색어 형태)로 원하는 프로그램의 기능과 디자인을 AI(제미나이)에 요구해 프로그램을 뚝딱 완성하는 개발 방식입니다. 교사는 개발자가 아닌 기획자이자 지시자 역할을 수행합니다.

2. 초보자용 핵심 3단계 개발 프로세스

1단계: 구상 및 프롬프트 복사

만들고자 하는 기능(자리 배치, 발표자 뽑기 등)을 구상하고, 실습 프롬프트를 복사합니다.

2단계: 제미나이 입력 및 소스코드 복사

gemini.google.com에 접속해 복사한 프롬프트를 넣고, AI가 준 완성형 HTML 코드 블록 우측 상단의 '복사(Copy)'를 클릭합니다.

3단계: 메모장 저장 및 실행 (매우 중요!)

컴퓨터 보조프로그램에서 [메모장(Notepad)]을 열고 코드를 붙여넣습니다. [파일] -> [다른 이름으로 저장]을 클릭한 후 아래 조건으로 저장합니다.

  • 파일 이름: 프로그램이름.html (예: seat.html)
  • 파일 형식: 반드시 '모든 파일 (*.*)'으로 변경
  • 인코딩: 반드시 'UTF-8'로 선택

저장 후 생성된 .html 파일을 더블클릭하면 크롬 브라우저에서 실행됩니다.

3. 실습용 핵심 프롬프트 복사 & 입력 가이드

🪑 예시 ①: 자리 배치도 생성기 프롬프트
"초등학교 학급운영을 위한 '학급 자리 배치도 생성 프로그램'을 만들고 싶어. HTML, CSS, JavaScript를 단 하나의 파일로 결합해서 완성도 높은 웹 페이지를 만들어줘. 조건은 다음과 같아: 1) 가로 줄(행)과 세로 줄(열) 수를 교사가 숫자로 설정할 수 있어야 해. 2) 학생 이름을 줄바꿈이나 쉼표로 입력해 무작위 자리 배치 버튼을 누르면 랜덤 섞여서 배치돼야 해. 3) 드래그 앤 드롭으로 자리를 상호 교환할 수 있어야 해. 4) 입력한 명단은 브라우저 localStorage에 저장되어 껐다 켜도 유지되게 해줘."
🎉 예시 ②: 모둠 & 룰렛 발표자 추첨기 프롬프트
"발표자를 뽑고 모둠을 짜주는 '모둠 및 발표자 추첨기'를 만들고 싶어. 단일 HTML 파일로 짜줘. 1) 탭 메뉴로 룰렛 추첨과 랜덤 모둠 구성 분리. 2) 학생 이름을 입력하고 룰렛 돌리기를 누르면 원형 룰렛이 돌며 당첨자를 선정. 3) 당첨 시 모달 창이 뜨고 브라우저 음성 합성(Speech Synthesis TTS)을 이용해 목소리로 당첨 학생 이름을 안내하고 폭죽(Confetti)이 터지는 애니메이션을 추가해줘. 4) 명단은 localStorage에 자동 보존되게 해줘."
📅 예시 ③: 오늘의 학급 안내판 & 타이머 프롬프트
"교실 TV에 띄우는 '오늘의 학급 안내판 대시보드'를 단일 HTML 파일로 코딩해줘. 1) 어둡고 깔끔한 다크 테마와 밝은 라이트 테마 토글 버튼. 2) 실시간 시간과 뽀모도로 타이머(5,10,20,30분 설정 가능, 완료 시 알람음 및 음성 종료안내 송출). 3) 1~6교시 시간표와 준비물을 입력하고 고칠 수 있는 편집형 시간표 테이블. 4) 체크리스트형 알림장과 청소 구역/급식 정보 입력 칸. 5) 모든 수정 상태는 localStorage에 실시간 자동 저장되어 새로고침해도 유지되게 해줘."

4. 긴급 문제 해결법 (트러블슈팅 FAQ)

현상 해결 방법 및 AI 대화 팁
한글 폰트가 깨지고 이상한 외계어로 나와요. 메모장에서 저장할 때 인코딩이 UTF-8로 되어 있지 않기 때문입니다. 파일 다른이름으로 저장시 인코딩 설정을 꼭 확인하고 덮어씌워 보세요.
버튼을 눌러도 반응이 없고 타이머가 안 가요. 제미나이 채팅창에 다시 물어보세요:
"방금 짜준 코드가 실행 시 버튼 작동이 안 돼. 스크립트 에러를 점검하고 완전히 실행 가능한 단일 HTML 소스코드로 다시 줘."
학급 학생 수에 맞게 카드 디자인을 넓히고 싶어요. 디자인 커스터마이징을 요구하세요:
"학급 카드가 더 널찍하고 파스텔톤 초록색을 기본 강조 컬러로 사용하게 카드 스타일 CSS를 수정해줘."
